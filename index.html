Blacklist

Seven builds, ranked by how much they matter to an embedded team. Pick a target.

  1. Uppsala team project · 1DT195

    Wireless Backscatter & Network-Wide Consensus

    A low-power wireless protocol built on backscatter tags. I planned and coded two optimisations, software-defined forward error correction and adaptive bitrate switching, and did hands-on physical-layer packet measurements and power tuning.

    A tag that speaks without a voice of its own, borrowing the breath of a distant carrier.

    Built with
    C/C++nRF52840CC1352P7Raspberry PiJupyter
    Repository
  2. Uppsala · 1DT106 & 1DT108

    Formally Verified Embedded C

    Sorting, searching and more, written in C/C++ with ACSL specifications and proved correct with Frama-C, including the course's final embedded project.

    Every loop bound sworn by contract. The prover does not forgive.

    Built with
    C/C++Frama-CACSLZephyr
  3. Solo build

    Vision-Controlled 19-DoF Robotic Hand

    A real-time pipeline that maps 21 3D hand landmarks from MediaPipe onto the 19 actuators of a TIAGo Hey5 hand in Webots. Double-mapping normalisation and vector kinematics stop mesh clipping, and a live HD stream over UDP keeps teleoperation low-latency.

    Raise your hand, and a hand of steel answers in kind.

    Built with
    PythonMediaPipeOpenCVWebotsUDP
    Repository
  4. AUST research · IEEE INDISCON 2025

    Hybrid Quantum-Classical Alzheimer's Classifier

    A CNN joined to an 8-qubit parameterised quantum circuit, wrapped as a PyTorch layer: 96.26% accuracy on 4-class MRI, ahead of DenseNet-169, EfficientNet-B7, VGG-16 and ResNet-50. I wrote the code and the Grad-CAM explanations, which a physician validated.

    Eight qubits, bound to a mind of convolutions, to read what memory forgets.

    Built with
    PyTorchPennyLaneGrad-CAM
    Paper
  5. AUST research · IEEE PEEIACON 2024

    NeuroMindscape CNN

    I designed a lightweight 7-layer Keras CNN that classifies four dementia stages at 97.05% accuracy, using Albumentations to correct heavy class imbalance (only 64 moderate-stage images).

    Seven layers deep, light enough to carry.

    Built with
    KerasCNNAlbumentations
    Paper
  6. Self-directed learning

    gem5: CXL-Attached NPU & LLaMA Offload

    I taught myself the gem5 full-system simulator by modelling a CXL-attached NPU and offloading LLM work to it. A learning project in computer architecture, not a research result.

    A machine within the machine, studied by lamplight.

    Built with
    gem5C++Python
    CXL NPULLaMA offload
  7. AUST coursework

    Digital Hardware from the Gates Up

    ALUs, a Booth multiplier and SAP computers designed and simulated in Proteus 8, plus 8086 assembly programming.

    Where it began: in the gates, before any kernel.

    Built with
    Proteus 88086 assemblyDigital logic
