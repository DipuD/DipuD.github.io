# dipud.github.io

Portfolio of Dipon Deb Dipu, M.Sc. student in Embedded Systems at Uppsala University.

A single static page with two switchable styles: STREET (night pursuit) and SOULS (gothic golden tree). Press **S** on the site to switch.

- `index.html`: the whole site
- `img/`: portraits, painted backdrops and car renders (original artwork)
- `cv/`: one-page CV
