# dipud.github.io

Portfolio of Dipon Deb Dipu, M.Sc. student in Embedded Systems at Uppsala University.

The page is laid out as the floorplan of an FPGA SoC. Scrolling walks a signal from configuration and the processing system through the logic fabric, DSP slices, block RAM, transceivers and GPIO, out to the I/O bank.

- `index.html`: the whole site (GSAP, ScrollTrigger and Lenis load from CDNs)
- `img/`: portraits
- `cv/`: CV
